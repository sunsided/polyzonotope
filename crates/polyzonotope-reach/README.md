# polyzonotope-reach

Validated reachable-set over-approximation of nonlinear dynamics with sparse polynomial zonotopes from [`polyzonotope`](https://crates.io/crates/polyzonotope), by conservative polynomialization (Althoff, HSCC 2013).

Work in progress, not released yet. See the [polyzonotope repository](https://github.com/sunsided/polyzonotope) for the plan.
